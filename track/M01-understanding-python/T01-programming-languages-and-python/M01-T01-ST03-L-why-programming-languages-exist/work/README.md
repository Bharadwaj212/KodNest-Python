# Why Programming Languages Exist

## Why Does a Computer Need Instructions?

A computer has zero intelligence of its own and relies on exact step by step instructions to know what to do.

## Why Can We Not Build Applications Using Normal Human Language?

A computer can't understand the human language it will only understand the machine language. Like 0's and 1's. So we can not build applications using Human Language.

## What Problem Do Programming Languages Solve?

According to the requirements any problem it can solve using the Instructions written in Programming Languages by using the logic we can build Applications for the Required Problem so the programming language solve the Problem by communicating with the computer.

## Why Is Machine Language Difficult for Humans?

Machine Language is difficult for humans because it consists entirely of unreadible strings of 1's and 0's tailored strictly to a processor's physical hardware rather than human logic.

## How Does Python Help?

Python translates simple,English-like code into binary for you, hiding all the complex hardware and memory management details.

## My Final Understanding

A programming language acts as a bridge between human logic and computer hardware.

Python allows a developer to write simple, English-like instructions without managing binary or memory details.

A computer follows the binary instructions and executes them.
